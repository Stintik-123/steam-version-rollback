# Хуки в интерфейс Steam

Есть два разных способа встроиться в интерфейс, и в проекте используются оба,
но для разных задач.

## 1. Секция в «Версиях и бета-версиях» — уже работает, без патчей

`frontend/inject.tsx` раз в 800 мс ищет на экране страницу свойств игры по
заголовку «Скрытые версии» (список языков — в `MARKERS`) и монтирует в её
контейнер React-корень с панелью. Патчи JS для этого не нужны.

Почему так: патч JS — регулярка по минифицированному коду конкретной сборки
клиента, он ломается от любого обновления Steam. DOM-инъекция переживает
обновления лучше, но всё равно завязана на текст заголовка и вёрстку.

Если блок не появился:

- проверьте консоль Steam UI на строку `[Version Rollback]` — там будет причина;
- откройте резервный вход: Настройки → Millennium → Version Rollback;
- добавьте свой язык в `MARKERS` в `frontend/inject.tsx` и пересоберите.

## 2. Патчи JS (`backend/patches.lua`) — каркас, не используются

Нужны только если захочется встроиться не в готовую страницу, а в произвольное
место React-дерева (например, кнопка в шапке свойств). По умолчанию список
`DEFINITIONS` пуст.

Формат (как в официальном шаблоне `SteamClientHomebrew/PluginTemplate`):

```lua
{
  find = [[<RE2-регэксп, накрывающий нужный кусок chunk-файла>]],
  file = [[chunk~[0-9a-f]+\.js]],
  transforms = {
    {
      match   = [[<что именно меняем внутри find>]],
      replace = [[<на что; \1 — группы из match; #{{self}} — наш фронтенд>]],
    },
  },
}
```

`#{{self}}` подставляет объект, экспортированный из `frontend/index.tsx` с
пометкой `/** @ffi */`. Сейчас наружу отдан только `execConsole` — для вставки
React-элементов понадобится добавить в `index.tsx` отдельный `/** @ffi */`
экспорт с компонентом.

## Порядок подбора

1. Включите в настройках плагина «Хуки в интерфейс Steam» (ключ
   `enable_ui_hooks` в конфиге плагина). Пока патчей нет, в лог уйдёт
   предупреждение — это ожидаемо.
2. Откройте DevTools окна `SharedJSContext` и выполните `tools/probe.js`.
   Скрипт покажет, доступен ли `SteamClient.Console.ExecCommand` и какие
   `chunk~*.js` загружены.
3. Найдите в нужном chunk фрагмент, который рендерит секцию свойств игры, и
   снимите с него якорь — короткий уникальный кусок кода.
4. Впишите патч в `DEFINITIONS` в `backend/patches.lua` и перезапустите плагин
   (`starlight watch` перезапускает сам).
5. Если патч не применился — в логе Millennium будет строка о неудачном матче.
   Не «подкручивайте» регулярку вслепую: сначала проверьте якорь в DevTools.

## Риски

- Патч применяется к файлам клиента; после обновления Steam якоря почти наверняка
  изменятся.
- Ошибка в `replace` ломает окно, в которое внедряемся. Держите `enable_ui_hooks`
  выключенным, пока патч не проверен.
- Хуки не влияют на саму загрузку депо: она идёт через консольную команду
  `download_depot`, а не через UI.
